### Overview
This project provides a sleek, responsive, and culturally optimized countdown landing page designed for the GCC market. Whether you are launching a new tech product, a brand, or a corporate event, this page helps build anticipation with a clean UI, an interactive agenda, and a newsletter subscription integration.

### Features
*   **RTL Optimized:** Built with full Right-to-Left (RTL) support for perfect Arabic typography and layout alignment.
*   **Live Countdown Timer:** Real-time synchronization to ensure your audience knows exactly when the event begins.
*   **Dynamic Agenda:** A clean, readable timeline section to showcase event highlights.
*   **Subscription Form:** A dedicated section to capture lead emails for future updates.
*   **Zero-Dependency:** Pure Vanilla JS, ensuring high performance and fast load times.
*   **Mobile-First Design:** Fully responsive layout that looks stunning on all devices.

### Localization Notes
*   **Language:** The content is primarily in Arabic (MSA) to resonate with the target audience.
*   **Direction:** The layout uses CSS `dir="rtl"` to ensure proper flow for Arabic speakers.
*   **Formatting:** Date and time formats are localized for regional standards.
